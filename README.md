# 🍽️ Global Restaurant Data Analysis

## 📌 Project Overview

This project analyzes global restaurant data using Microsoft Power BI. The dashboard helps explore restaurant information, compare cities, and understand restaurant distribution through data visualizations.

## 🎯 Project Objectives

- Analyze restaurant data across different locations.
- Compare the number of restaurants across cities.
- Understand restaurant distribution.
- Identify patterns and trends in the dataset.
- Present insights using Power BI dashboards.

## 🛠️ Tools and Technologies

- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Visualization
- Data Analysis
